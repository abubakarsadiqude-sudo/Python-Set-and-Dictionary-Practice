# Python Set and Dictionary Practice

## About This Repository

This repository contains 10 Python programming practice tasks based on two important Python data types: **Sets and Dictionaries**.

These exercises are designed to improve programming skills, logical thinking, and problem-solving abilities.

## Learning Objectives

- Understanding Python Sets and Dictionaries.
- Creating and accessing sets and dictionaries.
- Adding, updating, and deleting elements.
- Removing duplicate values.
- Performing set operations.
- Working with nested dictionaries.
- Searching and filtering data.
- Solving practical programming problems.
